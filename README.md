
# Travel Multi-Agent Assistant

A travel planning assistant built using Google ADK
and Gemini. It uses specialized agents for destination
recommendations, itinerary planning, and budget estimation.

## Requirements
- Python 3.10+
- Google Gemini API key

## Setup

1. Clone the repository:

   git clone YOUR_GITHUB_REPOSITORY_URL
   cd YOUR_REPOSITORY_NAME

2. Install dependencies:

   pip install google-adk

3. Create a `.env` file in the project directory:

   GOOGLE_API_KEY=your_google_api_key

4. Run the agent:

   adk web
