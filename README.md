# Multi-Agent Travel Planning Assistant

A travel planning application built using **Google Agent Development Kit (ADK)** and **Google Gemini**. The system uses a coordinated team of specialized AI agents to simplify travel planning by recommending destinations, generating personalized day-by-day itineraries, and estimating travel expenses.

The application demonstrates multi-agent orchestration using parallel execution, where independent agents handle specific tasks and a central coordinator combines their outputs into a comprehensive travel plan.

**Key Features**
- Destination recommendations based on user preferences.
- Personalized day-by-day itinerary generation.
- Estimated travel budgets covering accommodation, food, transportation, and activities.
- Multi-agent coordination using Google ADK.
- Parallel execution of specialized agents for efficient task handling.

**Tech Stack:** Python, Google ADK, Google Gemini, Multi-Agent Systems.
## Requirements
- Python 3.10+
- Google Gemini API key

## Setup

1. Clone the repository:

   git clone YOUR_GITHUB_REPOSITORY_URL
   cd YOUR_REPOSITORY_NAME

2. Install dependencies:

   pip install google-adk

3. Create a `.env` file in the project directory:

   GOOGLE_API_KEY=your_google_api_key

4. Run the agent:

   adk web
